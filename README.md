# EPOX web

Náhodný web s vlastním terminálem (cmd) a třemi tlačítky dole.

## Co tu je

| Soubor | K čemu je |
|---|---|
| `index.html` | kostra stránky |
| `style.css` | vzhled (barvy, rozložení) |
| `script.js` | terminál, karty a 3 tlačítka |
| `README.md` | tento popis |

## 3 tlačítka

1. **📜 Co jsme dělali** – co jsem dělal já, co Claude a nastavení Claude.
2. **✅ Kontrola kódu** – otevře oficiální [W3C HTML validátor](https://validator.w3.org/) s tímhle webem.
3. **📝 Kontrola v Markdownu** – otevře oficiální [W3C CSS validátor](https://jigsaw.w3.org/css-validator/) se souborem `style.css`.

Vlastní kontrola (18 testů + W3C) je v terminálu: příkaz `kontrola`, výsledek v Markdownu příkaz `md`.

## Jak to vzniklo

Celý postup, commity a kód s vysvětlením: složka [`postup/`](postup/) (nasazeno na Vercelu).

## Příkazy v terminálu

`help`, `cls`, `cas`, `datum`, `echo`, `vtip`, `fakt`, `kostka`, `color`, `matrix`, `ver`, `whoami`, `kontrola`, `md`, `historie`

Šipky ↑ ↓ = předchozí příkazy.
